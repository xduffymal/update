# Package contents

The ZIP preserves all root Python source, SQL schemas, dependency lists, relevant Markdown documentation, templates, static files, tests, tools, public data, fitted model versions and complete local checkpoint directories. It includes both consistent SQLite snapshots, an official MSG parser test fixture, the latest cited poster and teacher data-source package, fresh and historical evidence, and demo inputs.

Excluded: virtual environment, pip cache, session key, .env files, Git internals, duplicate older ZIPs, unrelated IoT slide decks, and temporary verification databases / temporary trained neural models. Temporary model runs are represented by logs, metrics and test outputs, while the runnable main models/checkpoints remain included. Historical recovered source and alternate -Mal files are preserved, but the active entry point is run.py with the unsuffixed modules.

Both root databases retain account records and password hashes as requested. They are preserved project snapshots. The separate demo helper lets each recipient choose their own password instead of changing those accounts.

The dated integration report is authoritative for this handoff. Earlier TESTING_REPORT.md is retained as historical documentation. New-machine dependency installation is required; compiled local environments are not distributed.
